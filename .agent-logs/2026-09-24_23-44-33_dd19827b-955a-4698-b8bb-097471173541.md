   - **Authentication & Ownership**: Verifies caller via Supabase session cookie or Bearer token; enforces server-side ownership (`meeting.user_id === user.id`). Returns `401 Unauthorized` for unauthenticated requests and `403 Forbidden` for cross-tenant access.
   - **Signed R2 Access**: Generates a temporary pre-signed R2 GET URL (`createPresignedDownloadUrl`) for the meeting's recording.
   - **Soniox Submission**: Submits the pre-signed URL to Soniox async STT.
   - **State Persistence**: Stores `soniox_job_id` on both `meetings` and `recordings` tables and transitions status from `uploaded` → `transcribing`.
   - **Idempotency**: Prevents duplicate job submissions when a meeting is already transcribing.
   - **Status Query**: Supports `GET /api/meetings/[id]/transcribe` to query live Soniox job status.
