   - React was only passing the URL inside `<source src={playbackUrl} />` instead of `<video src={playbackUrl} ...>`. In modern browsers (Chrome/Edge), omitting `src` on the `<video>` element causes video pipeline initialization delays when pages mount dynamically.

3. **`preload="metadata"` vs `preload="auto"`:**
   - With `preload="metadata"`, the browser only fetched container headers and refused to decode initial video frames, leaving the container in a dark blank buffering state.

4. **Upload Completion Bottleneck:**
   - In [`MyCalls`](file:///c:/Users/DeLL/Desktop/SidePROJECTs/FathomClone/src/components/my-calls.tsx#L198), after a file finished uploading 100% to Cloudflare R2, the app waited on an 8-second client-side duration probing promise before calling `/api/recordings/complete`. If probing was slow, the user suffered an artificial multi-second lag before the recording appeared.
